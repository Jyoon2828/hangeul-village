# 한글 마을 · 간판 탐험대

초등학교 4학년 국어 2단원 「우리말 우리글」 마무리 게임입니다.

## 실행
압축을 풀고 index.html을 Chrome 또는 Edge로 엽니다. 인터넷 연결 없이 활동할 수 있습니다. 기기별 브라우저에 자동 저장되며, 완성 작품은 PNG로 내려받습니다. 시크릿 창에서는 창을 닫으면 기록이 지워질 수 있습니다.

## GitHub–Vercel 배포
1. 새 GitHub 저장소를 만듭니다.
2. 압축을 푼 파일을 저장소 최상위에 올립니다. zip 자체를 올리지 않습니다.
3. Vercel에서 저장소를 가져옵니다.
4. Framework Preset은 Other, Build Command는 비움, Output Directory는 . 으로 설정합니다.
5. Deploy 후 배포 주소를 학생에게 공유합니다.

## 수업 흐름
주변 간판 이야기(5분) → 한글 지식 탐험(10분) → 3~4개 이름 만들기(15분) → 저장·발표(10분).
12개를 모두 완료할 필요는 없습니다. 같은 기기로 짝·모둠 활동을 해도 됩니다.

## 기능
- 기본 임무 12개: 가게·공원·아파트·생활 안내
- 한글의 우수성, 세종대왕·주시경·헐버트, 기본 맞춤법
- 오답 힌트와 무제한 재도전
- 이름·뜻 입력, 간판 색 변경, 작품 수정과 이름 도감
- 실제 주변 표현으로 자유 임무 최대 8개 추가
- 마을 이름·작성자 설정, 기기 내 자동 저장, 마을과 이름 뜻 PNG 저장

외래어도 우리말 어휘의 일부입니다. 외국어와 문화를 낮추지 않고 더 쉽고 친근한 표현을 찾도록 지도하세요. 창작의 뜻과 맞춤법은 자동 채점하지 않습니다. 기본 사례는 가상 사례이며 교사 실시간 수집 기능은 없습니다.

## 출처
앱의 수업 안내에 국사편찬위원회와 국립국어원 링크가 있습니다. 교과서 원문을 전재하지 않고 초등 수준으로 문제를 작성했습니다.

## 16비트 픽셀아트 업데이트
건물 12종·꽃밭·산책길로 구성된 생성형 이미지 원본을 assets에 포함했습니다. 화면과 PNG 저장 모두 같은 픽셀아트를 사용합니다. 간판은 이미지에 고정되지 않고 학생 입력에 따라 바뀝니다. 수정 전 진행 기록은 유지됩니다.

이미지 제작: 내장 이미지 생성 도구. 제작 프롬프트: 16비트 게임풍, 4열 3행의 동일한 크기 마을 구역, 빵집·꽃집·아파트·놀이터·미용실·책 쉼터·공원·반려동물 가게·운동관·포장 음식점·사진관·생활용품점, 꽃과 산책길, 빈 간판, 글자 없는 픽셀아트.

## 자연스러운 마을 배치 업데이트
4열 3행의 칸 배치를 없애고, 굽은 길과 작은 하천·다리로 이어지는 한 장의 연속 지도로 바꾸었습니다. 다층 아파트와 사진관 상가 빌딩, 생활용품 상가를 포함합니다. 작은 화면에서는 지도를 좌우로 밀어 탐험합니다. 자유 임무는 지도 아래 별도 간판으로 표시됩니다.

이미지 제작 프롬프트: 16비트 귀여운 픽셀 게임풍의 현대 한국 마을, 네모난 구획 없이 굽이치는 길과 비정형 꽃밭으로 연결된 가게 12곳, 7층 아파트, 4층 사진관 상가, 3층 생활용품 상가, 작은 하천과 다리, 빈 간판. 내장 이미지 생성 도구로 제작했습니다.

## 게임 UI 및 부착형 현판
간판을 건물 외벽 위치에 작은 나무 현판으로 부착하고, 장소별 폭·기울기를 적용했습니다. 긴 이름은 두 줄로 표시합니다. PNG 저장에도 같은 좌표와 현판을 적용합니다. 전체 화면은 짙은 남색 게임 패널과 픽셀 테두리, 주민 의뢰서·진행 단계·보상 안내·간판 공방으로 통일했습니다.

## 아바타 탐험
학생 아바타를 방향키/WASD, 화면 방향 버튼, 지도 클릭으로 이동합니다. 건물을 누르면 길의 연결 지점을 따라 이동하며, 가까이 도착한 후 아래의 주민 의뢰 버튼으로 미션을 시작합니다. 탐험가 이름과 옷 색을 설정할 수 있습니다. 팝업이 열려 있으면 이동은 멈춥니다. 지도는 화면 가장자리에 도달하면 좌우로 따라갑니다. 정해진 길 연결을 따라 움직이는 방식이며 자유 보행 물리 엔진은 아닙니다. 자유 임무는 지도 아래 버튼에서 엽니다.

## 전체 16비트 스타일 통일
마을 이미지를 굵은 픽셀, 단순화한 나무와 건물, 명확한 윤곽선으로 재제작했습니다. 기존 건물 배치와 이동 경로를 유지했고 길의 빈 입간판을 제거했습니다. 아바타와 공통 초록·나무·크림색 팔레트를 적용하고, 웹앱 바깥 배경도 풀빛 도트 무늬로 변경했습니다. 주민 초상은 코드로 그린 픽셀 캐릭터이며 이모지 장식은 단순한 도트 기호로 바꿨습니다.
이미지 제작: 내장 이미지 생성 도구. 프롬프트: 기존 마을의 배치와 12개 장소를 유지하는 16비트 스타일 변환, 굵은 사각 도트와 제한된 색상, 재료별 단순 음영, 부드러운 그라데이션과 세밀한 삽화 질감 제거, 길의 입간판 제거.

## 이야기형 탐험 게임
처음 입장하면 마을에서 온 편지 → 아바타 준비 → 첫 의뢰 안내가 나옵니다. 이후에는 추천 경로나 자유 이동으로 주민을 만나 지식 미션·창의 미션을 해결합니다. 간판을 새로 달면 주민의 감사 인사가 나옵니다. 기본 의뢰 4곳을 해결하면 최종 마을 이름 짓기와 한글 마을 완성 화면이 열립니다. 완성 화면에서 PNG 저장·추가 탐험이 가능합니다. 자유 임무는 기본 4곳 목표에 포함하지 않습니다. 이미 시작한 활동은 입장 화면을 건너뛰어 이어집니다. 새로 시작하면 이야기부터 진행합니다.

## 태블릿 전체 화면 UI
지도 중심의 화면 전체 배치를 적용했습니다. 기존 안내·진행 사이드바는 숨기고 목표·아바타 메뉴·이동 버튼·주민 안내를 지도 위에 겹쳐 표시합니다. 상단 메뉴에서 저장·자유 임무·마을 이름 변경·브라우저 전체 화면을 사용할 수 있습니다. 큰 지도는 아바타를 따라 가로·세로로 움직입니다. 16비트 스타일의 귀여운 탐험가 이미지로 교체했으며 옷의 청록색 영역만 선택 색으로 바꿉니다.
아바타 제작: 내장 이미지 생성 도구. 프롬프트: 투명 배경의 단일 정면 16비트 학생 탐험가, 큰 머리와 작은 몸, 둥근 갈색 앞머리·커다란 눈·분홍 볼·청록색 옷·작은 배낭·남색 반바지·갈색 신발, 선명한 사각 도트와 단순 음영.

## 아바타 조합 선택
머리 4종(짧은 머리·단발·긴 묶음머리·곱슬머리)과 의상 8종(탐험가·후드·멜빵·외투·바지 한복·치마 한복·세종대왕 의상·선비 옷)을 별도로 선택합니다. 총 32가지 조합을 미리 보고 입장할 수 있으며 탐험 중에도 변경할 수 있습니다. 세종대왕 의상은 붉은 왕실 옷과 코드로 그린 검은 익선관 장식으로 표현합니다. 선택은 기기에 저장됩니다.
이미지 제작: 내장 이미지 생성 도구. 프롬프트: 투명 배경의 4열 3행 16비트 아바타 부품 모음, 첫 행은 같은 귀여운 얼굴의 머리 4종, 나머지 두 행은 머리 없는 일상복·한복·붉은 왕실 용포·선비 옷 8종, 같은 크기와 정면 자세, 뚜렷한 도트 윤곽선.

## 기본 간판 표기 변경
기본 간판을 영문에서 한글로 적은 표현으로 바꾸었습니다: 스마일 베이커리, 플라워숍, 스카이 캐슬 아파트, 키즈존, 헤어숍, 북카페, 그린파크, 펫숍, 스포츠센터, 테이크아웃, 포토타워, 해피 플라자. 이미 학생이 만든 새 이름은 유지됩니다. 자유 임무 원문은 학생이 입력한 그대로 유지됩니다.
